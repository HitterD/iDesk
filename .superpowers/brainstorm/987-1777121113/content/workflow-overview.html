Lost Items — Workflow End-to-End

3 pendekatan workflow. Pilih yang paling sesuai kebutuhan.

A

Simple 2-Actor

Employee → Manager

  • Employee submit laporan hilang
  • Manager lihat list & update status
  • Status: REPORTED → FOUND | LOST
  • Notifikasi ke reporter saat status berubah
✓ Cepat diimplementasi  ·  ✓ Sudah 80% ada di codebase
✗ Tidak ada alur "orang menemukan barang"
B

3-Actor + Found Claim

Employee → Manager + Finder

  • Employee report barang hilang
  • Siapa saja bisa submit "Saya temukan barang ini"
  • Manager verifikasi & match report ↔ found claim
  • Status: REPORTED → CLAIMED → VERIFIED → RETURNED
  • Notifikasi di setiap transisi
✓ Alur lengkap  ·  ✓ Transparansi tinggi
✗ Lebih kompleks  ·  ✗ Perlu backend baru (found-claim entity)
C

Full Smart Workflow

Employee + Finder + Manager + Notif + Photo

  • Employee report + upload foto barang hilang
  • Siapa saja bisa "Saya temukan" + upload foto bukti
  • AI/Manager match: foto hilang ↔ foto temuan
  • Status timeline lengkap dengan audit log
  • Notifikasi real-time (WebSocket)
  • QR code pada barang kantor untuk quick-report
✓ Paling powerful  ·  ✓ Experience premium
✗ Scope besar  ·  ✗ Perlu file upload + notif infra
💡 Rekomendasi:

Mulai dari B (3-Actor) — cukup lengkap, tidak over-engineer. Infrastruktur notifikasi sudah ada di project ini. Foto upload bisa ditambahkan di sprint berikutnya.
