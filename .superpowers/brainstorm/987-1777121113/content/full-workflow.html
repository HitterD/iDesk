Status Chain

LostItemReport

REPORTED → INVESTIGATING → CLAIMED → VERIFIED → RETURNED
REPORTED / INVESTIGATING / CLAIMED → LOST (timeout / force-close)

FoundItemClaim

PENDING → MATCHED → RETURNED or REJECTED

Notification Triggers

Reporter dapat notif saat:
  • Laporan berhasil dikirim (konfirmasi)
  • Status berubah ke INVESTIGATING
  • Found claim masuk untuk laporannya
  • Claim di-verify → item MATCHED
  • Manager confirm RETURNED
  • Report di-close (LOST)
Finder dapat notif saat:
  • Claim berhasil dikirim
  • Claim MATCHED ✓
  • Claim REJECTED ✗ + alasan
  • Serah terima dikonfirmasi
Manager dapat notif saat:
  • Lost report baru masuk
  • Found claim baru masuk
  • Auto-detect: S/N match antara lost & found
  • Report mendekati timeout (7 hari)
