Halaman Dibutuhkan

Client
Report Lost Item ENHANCE
Form existing + foto upload (0–5), preview foto, validasi S/N, generate QR setelah submit
Client
My Lost Reports BARU
List laporan saya, status badge, timeline, QR code per item, tombol cancel
Semua User
Report Found Item BARU
Form: foto (0–5), lokasi, waktu, deskripsi. Jika dari QR scan, reportId pre-filled. Jika manual, pilih dari dropdown lost reports atau biarkan unlinked.
Manager
Lost Items Dashboard ENHANCE
Ganti dummy data → real API. Stats card, filter status, detail drawer dengan timeline log, tombol Update Status.
Manager
Found Claims Queue BARU
List semua found claims PENDING. Badge auto-hint jika S/N match. Klik → buka Match Review.
Manager
Match Review Panel BARU
Side-by-side: foto lost vs foto found, S/N comparison, data reporter vs finder. Tombol: MATCH ✓ atau REJECT ✗ + wajib tulis notes.
