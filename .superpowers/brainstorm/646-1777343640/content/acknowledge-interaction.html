A — Tombol "Done" inline per item

Setiap action item punya tombol ✓ Done di kanan. Klik = konfirmasi manual bahwa sudah ditangani. Item langsung hilang dari list.

Pro

  • Eksplisit & jelas
  • Kontrol penuh user

Kontra

  • Perlu klik ekstra
  • Bisa lupa klik
Auto-resolved saat ticket dibalas
Ticket #1234 belum dibalas
✓ Resolved otomatis — balas dikirim 14:32
Hardware Request menunggu approval
HIGH · Submitted 3 jam lalu

B — Auto-resolve berbasis status entity

Tidak ada tombol manual. Item hilang otomatis saat status entity berubah (ticket dibalas → resolved, hardware approved → resolved). Polling/socket driven.

Pro

  • Zero friction
  • Selalu akurat

Kontra

  • Tidak ada kontrol user
  • Butuh mapping status lengkap
Ticket #1234 belum dibalas 2 jam

Hardware Request menunggu approval
HIGH · Submitted 3 jam lalu

C — Hybrid: Auto-resolve + Snooze manual

Item hilang otomatis saat entitas di-handle. Tidak ada tombol "Done" — tapi ada Snooze untuk menunda reminder. Flow: klik → handle di halaman entity → kembali otomatis clear.

Pro

  • Natural workflow
  • Auto-resolve akurat
  • Snooze untuk edge case

Kontra

  • Lebih kompleks implementasi

Klik kartu untuk pilih, atau ketik preferensi di terminal
