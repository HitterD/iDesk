Preset Management — Pilih Pendekatan UI

Saat ini preset dikelola lewat modal dialog. Mana yang paling cocok untuk improve UX-nya?

A

Slide-over Panel (Drawer)

Panel dari sisi kanan layar. List preset di kiri panel, detail/edit di kanan panel. Tidak menutup halaman agents — user masih bisa lihat konteks. Quick-create, quick-edit inline.

+ Cocok untuk: Edit sering, bandingkan preset, drag-reorder
- Kurang cocok: Layar kecil, form permission yang panjang
B

Dedicated Sub-page / Tab

Tab "Presets" terpisah di halaman Agents. Full-page experience dengan list preset, editor permission yang lebar, preview live siapa yang pakai preset ini.

+ Cocok untuk: Banyak preset, permission editor yang kompleks, audit trail
- Kurang cocok: Navigasi terasa berat untuk perubahan kecil
C

Enhanced Modal + Quick Actions

Modal yang lebih besar (wider, 2-column). List preset di kolom kiri, live editor di kolom kanan. Plus tombol quick-apply langsung dari user card tanpa buka modal.

+ Cocok untuk: Iterasi cepat, familiar (extend yang ada), mobile-friendly
- Kurang cocok: Sudah ada masalah di modal saat ini, extend bisa warisi masalah
Konteks saat ini

Preset sekarang: modal list → klik edit → buka PagePresetEditor (modal lagi). Double-modal, kurang smooth. PresetDropdown di user card sudah ada tapi hanya apply, tidak manage.
