Site Isolation — Assigned To Dropdown

Agent SPJ hanya bisa assign tiket ke agent SPJ lain. Bagaimana cara terbaik menampilkan ini?

A

Silent Filter (Invisible)

Dropdown langsung hanya tampil agent dari site yang sama. Tidak ada label, tidak ada penjelasan — list sudah otomatis ter-filter. Admin/Manager tetap lihat semua site dengan group header per site.

Dropdown agent SPJ melihat:
🔵 Budi Santoso    🔵 Rina Kusuma    🔵 Ahmad Fauzi
(semua SPJ, tanpa label site)
B

Labeled Filter (Explicit)

Dropdown tampil dengan label "Site SPJ" di atas list. Agent tahu mereka hanya melihat sesama site. Ada badge site kecil di setiap nama agent.

Dropdown agent SPJ melihat:
Site SPJ • 3 agents
🔵 Budi Santoso SPJ
🔵 Rina Kusuma SPJ
C

Grouped by Site (Admin view only)

Agent biasa: silent filter (opsi A). Admin/Manager: dropdown dikelompokkan per site dengan header "SPJ", "SMG", "KRW", "JTB" — bisa assign ke siapa saja lintas site.

Admin/Manager melihat:
── SPJ ── Budi, Rina
── SMG ── Diana, Reza
── KRW ── Andi
Agent biasa: silent filter seperti opsi A
