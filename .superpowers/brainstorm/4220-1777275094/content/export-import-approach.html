Export / Import — Apa yang Perlu Disempurnakan?

Pilih semua yang ingin diperbaiki (multi-select)

1

Format Export Lebih Lengkap

Tambah export JSON (untuk backup/restore preset), export PDF dengan layout yang lebih rapi, dan export per-site (bukan hanya semua site sekaligus).

2

Pilih Field saat Export

Sebelum download, user bisa centang field mana yang mau di-export: nama, email, site, role, preset, status aktif, dll. Bukan dump semua field sekaligus.

3

Import Validation yang Lebih Jelas

Preview tabel sebelum import dengan highlight error per baris (merah), warning (kuning), dan OK (hijau). Tombol "Fix errors" yang langsung fokus ke baris bermasalah.

4

Import Mode: Create vs Update

Toggle pilihan: "Hanya tambah user baru" vs "Update user yang sudah ada jika email sama". Saat ini hanya create, tidak bisa bulk-update via CSV.

5

Export/Import Preset Permission

Export konfigurasi preset ke JSON, import di environment lain (staging → production). Berguna untuk backup dan replikasi konfigurasi permission.

6

Progress & Result Summary

Setelah import selesai, tampil ringkasan: berhasil X, gagal Y, skip Z. Download report error. Saat ini hanya toast notification singkat.

Klik semua yang relevan, lalu kasih tahu di terminal.
