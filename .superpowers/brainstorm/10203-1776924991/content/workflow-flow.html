Approval Workflow Flow

Pilih model alur persetujuan yang sesuai

USER ISI FORM
+ ttd + pilih atasan
↓
ATASAN TERIMA INBOX
notif + review form
↓
ATASAN TTD & SETUJU
atau tolak dengan alasan
↓
ICT/ADMIN TERIMA
buatkan akses VPN/user
↓
SELESAI ✓
user terima kredensial

A — Linear (Rekomendasi)

User → Atasan → ICT. 1 level persetujuan, langsung ke ICT setelah approve. Paling sederhana.

USER ISI FORM
+ ttd + pilih atasan
↓
ATASAN TTD & SETUJU
↓
✓
ICT EKSEKUSI
buat akses
✗
TOLAK
notif ke user
+ alur revisi jika ditolak

B — Linear + Reject Flow

Sama seperti A, plus user bisa revisi dan resubmit jika ditolak atasan. Lebih lengkap.

Pertanyaan tambahan — bagaimana atasan melihat form untuk ditandatangani?

X

Inline di notifikasi

Atasan klik notif → form muncul langsung dalam modal/panel, tanpa pindah halaman

Y

Halaman detail tersendiri

Atasan klik notif → diarahkan ke halaman detail form lengkap untuk review + TTD

Pilih workflow (A/B) dan cara atasan lihat form (X/Y), lalu balas di terminal.
