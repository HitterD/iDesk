3 Pendekatan Implementasi

Semua pakai: Layout A (calendar-first) + Style B (clean light) + Chip B (medium card). Perbedaan di interaction pattern detail event.

A

Popover Enhanced ⭐ Rekomendasi

Redesign total layout + style. Event klik buka enhanced popover yang lebih kaya info (status timeline, quick actions: reschedule/confirm). Sidebar collapsible dengan toggle button. Stats strip di header (scheduled/unscheduled/today/overdue). Filter technician jadi multi-select chips bukan dropdown.

Pros

  • Perubahan minimal pada logic/data fetching
  • UX familiar (popover sudah ada)
  • Cepat diimplementasi

Cons

  • Popover bisa terpotong di layar kecil
B

Detail Slide Panel

Klik event → sidebar kanan berubah jadi detail panel yang slide-in (replace Today/Unscheduled sementara). Tampilkan info lengkap + action buttons. Tombol X untuk kembali ke Today/Unscheduled view. Tidak pakai popover sama sekali.

Pros

  • Tidak ada popover overflow issue
  • Space detail lebih lega
  • Mobile-friendly

Cons

  • Kehilangan context Today/Unscheduled saat buka detail
  • Lebih banyak state management
C

Agenda Bottom Drawer

Calendar full-width tanpa sidebar. Klik tanggal/event buka bottom drawer yang slide-up dari bawah. Drawer tampilkan agenda hari itu + detail event yang diklik. Sidebar Today/Unscheduled jadi floating badge counter di pojok.

Pros

  • Kalender paling besar/lega
  • Pattern familiar dari mobile calendar

Cons

  • Perubahan paling besar dari struktur sekarang
  • Sidebar logic perlu direfactor signifikan

Rekomendasi: A — paling pragmatis, improvement signifikan tanpa refactor besar. Pilih atau ketik preferensi.
