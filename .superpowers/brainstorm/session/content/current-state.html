🔔 iDesk — Audit Sistem Notifikasi

Gue sudah baca semua kode. Ini state saat ini vs gap yang perlu diperbaiki.

✅ Sudah Ada
  • Bell icon + badge unread di Topbar
  • Popover preview 10 notif terbaru
  • InAppToast real-time (hilang 5 detik)
  • CriticalBanner (SLA/renewal, marquee)
  • NotificationCenter full page + filter
  • Sound: MESSAGE / CRITICAL
  • Multi-channel: email, Telegram, push
  • requiresAcknowledge + API acknowledge
  • Category: tickets, renewals, hardware, zoom, eform
❌ Gap / Problem
  • Toast 5 detik — terlewat kalau tidak lihat layar
  • Tidak ada "action inbox" — tugas pending tercecer
  • Semua notif terasa setara — tidak ada urgency visual
  • Tidak ada reminder re-surface notif unread lama
  • Sidebar tidak tunjukkan pending tasks
  • CriticalBanner bisa dismiss selamanya di session
  • Tidak ada "missed while away" summary
  • User/client tidak tahu ada respon tanpa buka app

Siapa yang paling sering kelewat? (pilih semua yang tepat)

A

User / Client

Tidak tahu ticket sudah direspon. Tidak ada reminder kalau belum ada update lama.

B

Agent / IT Staff

Ticket assigned tapi toast sudah hilang. Tidak ada queue view yang jelas mana yang urgent.

C

Admin / Manager

SLA breach atau renewal expiry tidak di-act cepat. Approval hardware/eform tertunda.

D

Semua Role

Masalah merata — sistem notifikasi secara keseluruhan tidak asserted enough.
