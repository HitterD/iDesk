Design: Perbaikan Bertahap — iDesk Notification Command Center

3 Fase commit terpisah · Backend → Frontend → Polish

FASE 1 — Backend P0/P1 (Critical)
notification-center.service.ts · notification.controller.ts
🗑 1. Hapus dead code: notificationQueue
Array dideklarasi tapi tidak pernah digunakan — baris 31–36. Hapus field dan semua referensinya.
🔒 2. Fix mutasi entity: Object.assign → spread
❌ Object.assign(prefs, updates)
✅ return this.preferenceRepo.save({ ...prefs, ...updates })
📌 3. Fix return type: Promise<any> → Promise<ActionItemsResponseDto>
getActionItems (baris 245) return any — ubah ke typed DTO yang sudah ada.
⚠️ 4. Fix error handling: new Error() → NotFoundException
updateCategorySettings (baris 235) throw raw Error → throw new NotFoundException() dari @nestjs/common.
🔧 5. Hapus dead counter variables di getActionItems
critical/high/normal counter (baris 247–249) dihitung ulang di akhir fungsi — counter pertama tidak dipakai. Hapus dan langsung annotate dari activeItems.
🔐 6. Fix unsafe cast di controller: as any → as NotificationType
body.notificationType as any → cast ke enum NotificationType yang sudah ada.
♾️ 7. Fix retry loop permanen di retryFailedDeliveries
Jika channelService tidak ada (isAvailable = false), retryCount tidak diincrement → item stuck selamanya. Tambah increment meski skip.
💾 8. Batasi ukuran digestBuffer (max 100 notif/user)
digestBuffer tidak dibatasi — tambah guard: jika buffer > 100, trim oldest entries.
FASE 2 — Frontend P1/P2 (Performance & UX)
ActionCommandCenter.tsx · useActionItems.ts · ReminderSettingsPanel
🖱 1. Snooze menu: tambah close-on-outside-click
const menuRef = useRef<HTMLDivElement>(null);
useEffect(() => {
  if (!showSnoozeMenu) return;
  const h = (e: MouseEvent) => {
    if (!menuRef.current?.contains(e.target as Node))
      setShowSnoozeMenu(false);
  };
  document.addEventListener('mousedown', h);
  return () => document.removeEventListener('mousedown', h);
}, [showSnoozeMenu]);
⚡ 2. Memoize grouped computation
Bungkus dengan useMemo([items]) — tidak re-filter setiap render.
♻️ 3. Ganti isRefreshing state → isFetching dari react-query
Hapus local state + handleRefresh async wrapper. Expose isFetching dari useActionItems hook langsung.
🛑 4. Fix memory leak ReminderSettingsPanel
Tambah AbortController di useEffect — abort saat unmount.
⏱ 5. Tambah staleTime: 30_000 + gcTime: 120_000 ke useActionItems
Mencegah fresh fetch setiap kali komponen mount dalam 30 detik sejak fetch terakhir.
