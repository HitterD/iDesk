# CSI (Customer Satisfaction Index) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Modul survei CSI (bintang 1–5) per unit ICT/HC dengan master data, periode per site, form responden ala Google Form bergaya Apple, dan report non-anonim + export Excel.

**Architecture:** Modul NestJS baru `apps/backend/src/modules/csi` (TypeORM, satu migration) dengan guard sendiri `CsiAdminGuard` yang menegakkan isolasi unit tanpa bypass ADMIN. Frontend fitur baru `apps/frontend/src/features/csi` (TanStack Query), halaman responden di `/client/csi` + sidebar staf, halaman admin di `/csi/admin/:scope`.

**Tech Stack:** NestJS 11, TypeORM 0.3, PostgreSQL, exceljs (backend export), React 19, TanStack Query 5, Tailwind 4, Radix UI, framer-motion, lucide-react. Test: Jest (backend), Vitest (frontend).

**Spec:** `docs/superpowers/specs/2026-10-25-csi-design.md`

## Global Constraints

- Skala nilai integer 1–5; semua dimensi tiap orang wajib diisi.
- Tanggal periode = tanggal kalender WIB, inklusif; konversi pakai `wibStartOfDate` / `wibEndOfDate` (`apps/backend/src/shared/core/utils/wib-date.util.ts`).
- Unit = `ServiceScope` (`ICT` | `HC`) dari `service-scope.util.ts`; jangan buat enum unit baru.
- Akses admin CSI: role `ADMIN` atau `MANAGER` **dan** `pageAccess['csi_admin_<scope lowercase>'] === true`. Tidak ada bypass ADMIN.
- Default role ADMIN mendapat `csi_admin_ict` tapi **tidak** `csi_admin_hc`.
- Satu submission per (periode, responden) — ditegakkan unique index DB, bukan hanya cek aplikasi.
- Report non-anonim: nama responden tampil. Tidak ada kalimat "jawaban dapat dilihat admin".
- Teks UI dalam Bahasa Indonesia. Desain mengikuti `DESIGN.md` (SF Pro stack, sapphire chrome, amber create button).
- Test backend dijalankan serial: `npx jest --runInBand <file>` satu file per kali.
- Komentar maks 1000 karakter; judul periode maks 150; intro/terima kasih maks 2000.

## Review Focus

1. Responden submit dua kali bersamaan (double-click / dua tab) → hanya satu tersimpan, yang kedua dapat 409 (Task 5 test `rejects concurrent duplicate via unique violation`).
2. ADMIN tanpa `csi_admin_hc` memanggil endpoint HC dengan scope di URL → 403, termasuk akses periode HC lewat id periode di endpoint ICT (Task 3 test `rejects period of other scope`).
3. Periode berakhir saat responden sedang mengisi → submit ditolak 410 dengan pesan jelas, form tidak hilang diam-diam (Task 5 test `rejects submit after endDate`).
4. Orang dinilai dinonaktifkan/di-HRIS-sync jadi inactive di tengah periode → tetap tampil di form dan report periode itu (snapshot nama di assignment) (Task 4 test `keeps inactive ratee in active period`).
5. Responden mode OPEN dari site lain mencoba GET form periode site lain → 404 (Task 5 test `hides period of other site`).

## Data Model (Task 1)

Semua tabel prefix `csi_`, PK uuid, `createdAt`/`updatedAt`.

| Tabel | Kolom penting | Constraint |
|---|---|---|
| `csi_dimensions` | `scope varchar(10)`, `name varchar(100)`, `description varchar(300) null`, `isActive bool default true`, `sortOrder int default 0` | idx(scope) |
| `csi_departments` | `scope`, `name varchar(100)`, `isActive`, `sortOrder` | unique(scope, lower(name)) |
| `csi_raters` | `scope`, `userId uuid FK users` | unique(scope, userId) |
| `csi_periods` | `scope`, `siteId uuid FK sites`, `title varchar(150)`, `intro text`, `thankYou text`, `startDate date`, `endDate date`, `respondentMode varchar(10)` (`OPEN`/`LISTED`), `createdById uuid` | idx(scope, siteId, startDate) |
| `csi_period_ratees` | `periodId FK cascade`, `userId uuid FK users`, `displayName varchar(150)`, `jobTitle varchar(150) null`, `sortOrder int` | unique(periodId, userId) |
| `csi_period_ratee_dimensions` | `periodRateeId FK cascade`, `dimensionId FK csi_dimensions`, `dimensionName varchar(100)`, `sortOrder` | unique(periodRateeId, dimensionId) |
| `csi_period_raters` | `periodId FK cascade`, `userId uuid FK users` | unique(periodId, userId) |
| `csi_responses` | `periodId FK`, `respondentId uuid FK users`, `departmentId FK csi_departments`, `departmentName varchar(100)`, `submittedAt timestamptz` | **unique(periodId, respondentId)** |
| `csi_response_items` | `responseId FK cascade`, `periodRateeId FK`, `periodRateeDimensionId FK`, `score smallint` CHECK 1–5 | unique(responseId, periodRateeDimensionId) |
| `csi_response_comments` | `responseId FK cascade`, `periodRateeId FK`, `comment varchar(1000)` | unique(responseId, periodRateeId) |

`displayName`, `jobTitle`, `dimensionName`, `departmentName` adalah snapshot saat dipasang/submit agar report periode lama stabil.

## API (prefix `/v1/csi`)

Admin (guard `JwtAuthGuard` + `CsiAdminGuard`, `:scope` = `ict`|`hc`):
- `GET|POST /admin/:scope/dimensions`, `PATCH|DELETE /admin/:scope/dimensions/:id` (DELETE = soft `isActive=false`)
- `GET|POST /admin/:scope/departments`, `PATCH|DELETE /admin/:scope/departments/:id`
- `GET|POST /admin/:scope/raters` (body `{ userIds: string[] }`), `DELETE /admin/:scope/raters/:id`
- `GET /admin/:scope/periods?siteId=`, `POST /admin/:scope/periods` (body boleh `copyFromPeriodId`), `GET|PATCH|DELETE /admin/:scope/periods/:id` (DELETE hanya jika belum ada response)
- `PUT /admin/:scope/periods/:id/ratees` body `{ ratees: { userId, dimensionIds[] }[] }` (replace-all; 409 jika locked)
- `PUT /admin/:scope/periods/:id/raters` body `{ userIds[] }` (replace-all; 409 jika locked)
- `GET /admin/:scope/periods/:id/report`, `GET /admin/:scope/periods/:id/respondents`, `GET /admin/:scope/periods/:id/responses/:responseId`
- `DELETE /admin/:scope/periods/:id/responses/:responseId` body `{ reason }` (min 5 char)
- `GET /admin/:scope/periods/:id/export` → xlsx
- `GET /admin/:scope/users?search=` (picker user aktif; id, fullName, jobTitle, site)

Responden (guard `JwtAuthGuard` saja):
- `GET /me/active` → daftar periode aktif eligible `{ id, scope, title, submitted }[]`
- `GET /me/periods/:id` → form (teks, departemen aktif, ratees tanpa diri sendiri + dimensi) atau `{ submitted: true, thankYou }`
- `POST /me/periods/:id/responses` body `{ departmentId, items: { periodRateeDimensionId, score }[], comments: { periodRateeId, comment }[] }`
